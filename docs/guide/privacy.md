## 10. 隐私说明

项目默认**本地优先**：麦克风音频、识别文本、默认角色的模型推理都在本机完成
（提醒、课表、备忘都只是本机 json 文件），默认本地角色断网也能用。
只有显式开启下列能力才会联网：API 角色（对话发给对应厂商）、天气 / `web` 等联网工具
（查询词发出去）、邮件（Microsoft Graph）、记忆同步（整理后的记忆，**不含 L1 原始对话**，
推到你自己的私有仓库）。这些开关都可以单独关掉，关掉后回到纯本地运行。

这些文件是**你自己的数据**，都在主项目的 `.gitignore` 里（不会被推到主仓库；
记忆同步走的是另一个你自己的私有仓库）：

| 位置 | 是什么 | 生命周期 |
| --- | --- | --- |
| `sessions/session-*.jsonl` | 每次对话的原始记录（L1） | 归档进记忆库后，**超过 30 天自动清**（`[memory] keep_session_days`） |
| `data/memory/<角色>/` | 记忆（L2 情节 / L3 事实） | 默认只在本地；开同步后镜像到你自己的私有仓库（见第 15 节），L1 原始对话不上传；删掉就等于失忆 |
| `data/vision/` | 截屏 / 摄像头拍到的画面 | 想清就整个删掉，不影响运行 |
| `data/knowledge/` | 你给它的世界观/资料 | 随你放 |

想立刻清原始对话：`python main.py memory --prune --apply`（只删**已归档**过的，没进记忆库的不动）。
